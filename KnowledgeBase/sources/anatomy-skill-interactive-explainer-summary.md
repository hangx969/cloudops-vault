## 摘要

原文介绍 Anatomy Skill 如何用可操作的结构模型解释机械和技术原理，并指出初学者仅看精细动画仍可能难以理解。作者进一步让 Agent 在动画基础上生成带讲解和配音的视频，展示机械表、显卡、TCP 三次握手、刹车和榫卯等案例。文章记录了模型设置、额度消耗、生成耗时和配音调整，并将其与文字、图解、交互网页和定制视频四种学习形式联系起来。

## 关键知识点

1. Anatomy 通过零件、结构和运动解释原理；机械表演示支持操作发条、观察运动和拆解结构，发动机案例展示内部剖面。
2. 交互模型与讲解视频承担不同作用。前者便于探索结构，后者通过旁白说明当前组件、变化及其原因；视频是作者继续要求 Agent 制作的产物。
3. 原文保留了安装请求和机械表交互演示提示词；讲解深度可按需求调整。macOS 默认合成语音不理想时，作者通过后续请求改用火山配音。
4. 显卡案例围绕用途、组件、组装、一帧计算、计算速度、连续画面、散热及输入输出组织讲解，并让画面展示或高亮当前组件。
5. 作者记录，约 5 分钟的视频消耗约为其 200 美元 Claude Max 会员周额度的 1%；Opus 5.5 Ultra 生成约 5 分钟视频耗时约 1.5 小时。Sonnet 5.5 高推理强度也被用于较简化的自学版本。
6. 文字适合查阅，图解适合展示关系，HTML 适合操作探索，视频适合逐步讲解；使用哪一种取决于主题、基础和学习阶段。
7. 画面精细不代表内容正确；具体参数、机械关系、计算过程、关键原理和旁白发音仍需核对。

## 值得注意

- Anatomy 的核心输出范围已对照项目说明：交互图形可交付为 HTML、SVG 或组件。原文的配音与视频制作经验不应写成 Skill 自带的一键视频导出功能。
- 原文将视频生成提示词放在截图中；本次按要求忽略图片与视频，未补写截图里的提示词。保留文字中可见的安装请求、交互提示词、案例说明与体验数据。
- 模型名称、推理档位、会员额度、耗时及效果评价均为原文记录，未复现生成流程，也未独立核实当时的产品配置；额度比例不应推广为固定成本。
- Transformer 案例中的会话限制为作者陈述，未核实其触发机制。通信专业同事的反馈也属于个体评价。
- 关于 ASD-STE100 的内容保留为写作与解释方法，中文借用其原则不等于标准合规；详见 [[AI/行业动态/Karpathy-大模型输出理解技巧-文字图解网页视频]]。
- 本文与 [[AI/AI-视觉/AI-Animation-Skill-科普动画]] 分别讨论结构模型与模板动画，作为独立文章保留。
