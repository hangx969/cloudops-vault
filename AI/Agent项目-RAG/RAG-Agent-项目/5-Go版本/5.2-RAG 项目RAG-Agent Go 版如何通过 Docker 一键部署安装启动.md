RAG 项目RAG-Agent Go 版 AI 知识库代码库已经完成了，为了降低上手难度，这里提供了 <u>Go</u> 版 Docker 一键部署方案，基本上一天就能完成 MinIO、ElasticSearch、Redis、MySQL、Kafka 等前置环境的安装。

手把手教大家！

## 一、申请向量化 API key

登录阿里百炼，访问 [<u>https://bailian.console.aliyun.com/?tab=model#/api-key </u>](https://bailian.console.aliyun.com/?tab=model#/api-key)，申请并复制 API key，随后粘贴到 config.yaml 中：

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224415979.png)

在这里可以查看 [<u>https://bailian.console.aliyun.com/?tab=model#/model-market/all </u>](https://bailian.console.aliyun.com/?tab=model#/model-market/all)，通用文本向量-v4

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224418702.png)

会免费赠送一批额度，基本够 RAG-Agent 使用了。😄 等用完了再充值。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224421819.png)

接着把申请到的 API key 粘贴到 config.yaml 中。注意，我们这里使用的是 2048 维，一定要和 ElasticSearch 匹配。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224425147.png)

## 二、申请 DeepSeek API key

我们这里的模型用的是 DeepSeek。

DeepSeek API 的申请很简单，访问 [<u>https://platform.deepseek.com/api_keys </u>](https://platform.deepseek.com/api_keys)，然后创建 api key 即可。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224428170.png)

记得先充值。

复制 key 并填入 `config.yaml` 即可。URL 填写为 [<u>https://api.deepseek.com/v1 </u>](https://api.deepseek.com/v1)，model 填写为 `deepseek-chat`，key 填写刚刚申请的 key。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224431216.png)

## 四、安装 docker

Docker 官网： [<u>https://www.docker.com/</u>](https://www.docker.com/)



Windows 用户可以参考之前 Java 版本的教程：

[<u>✅Docker 部署RAG-Agent（懒人福音）</u>](https://paicoding.com/column/10/10)



这里再说一下 macOS 版本：通过官网下载并拖到“应用程序”后，启动时可能会一直弹窗。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224443630.png)

弹窗会一直出现，点击“完成”也没用。重启后把应用程序删掉，弹窗才消失。我查了很多原因，有人说是签名不正确，也有人说 Docker 和 macOS 的理念冲突导致误判；反正就是打不开。

于是我想到用 Warp 这款工具，让它通过 Homebrew 帮我安装，直接输入提示词“我想安装 Docker，下载的 Docker dmg 会提示不安全，有其他办法吗”

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224446803.png)

一开始没问题，但等安装的时候冲突了，可能前面没有卸载干净。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224449876.png)

然后让 Warp 一步步解决问题。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224453355.png)

解决掉无数个冲突后，终于安装成功。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224456334.png)

执行 `open -a Docker` 后，确实可以打开 Docker 了。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224500003.png)

## 五、启动项目

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224522771.png)

如果你是新手，看到代码飙红也不要慌。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224526227.png)

在 GoLand 中打开终端，执行 `go mod tidy`，重新加载依赖。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224529295.png)

**这里提醒两点，如果你本地已经安装了 MySQL 和 Redis，也不想在 Docker 中拉取，那么就可以在配置文件这里直接改成你本地的密码**。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224532598.png)

比如说 MySQL 的密码就改成你本地的，Redis 的也改成你本地的，如果你想使用 Docker 拉取的镜像，就可以保持现状。

接着新开一个终端，仍然在项目根目录下执行：`go run cmd/server/main.go`

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224535268.png)

假如以上这些问题你都没有出现，那么恭喜你 🎉， **RAG-Agent Go 版的后端你已经启动成功了。**

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224539031.png)

接下来在终端切换到前端目录 paismart-go/frontend，先执行 `pnpm i` 安装前端依赖。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224542507.png)

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224545583.png)

然后执行 `pnpm run dev` 启动前端。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224549169.png)

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501224552147.png)
