申请 DeepSeek API 很简单：访问 [<u>https://platform.deepseek.com/api_keys </u>](https://platform.deepseek.com/api_keys)，然后创建 API key，并将 key 填入 `application.yml` 即可。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501223649469.png)

记得充钱。

URL 填写为 [<u>https://api.deepseek.com/v1 </u>](https://api.deepseek.com/v1)，model 填写为 `deepseek-chat`

key 填刚刚申请的 API key。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501223652928.png)

项目启动后，打开聊天助手，输入一段内容进行测试。若收到回复，说明配置正确。

![](https://raw.githubusercontent.com/hangx969/upload-images-md/main/20260501223658054.png)
