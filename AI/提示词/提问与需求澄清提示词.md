# 提问与需求澄清提示词

用于在给答案之前明确目标、事实、假设和约束，避免 AI 针对错误的问题给出完整答案。

## 苏格拉底式问诊

适合自己也说不清真正问题时使用。最多六问，每次只问一个，并且只追问可能改变结论的信息。

~~~markdown
我的困惑是：【尽量具体地描述发生了什么、你怎么理解，以及你卡在哪里】。先不要给建议。请对我进行一次苏格拉底式问诊，通过最多6个问题，帮我找到真正值得回答的问题。
请遵守这些规则：
1. 每次只问一个问题，根据我的回答决定下一问，不要提前给我一整套问卷；
2. 优先区分我说的是可验证的事实、对事实的解释、价值判断，还是我希望实现的目标；
3. 检查关键词是否含糊、我默认了哪些前提、证据来自哪里、有没有相反解释，以及结论成立或不成立分别意味着什么；
4. 每次提问前，用一句话说明上一条回答让你更新了什么判断；
5. 只问可能改变结论的问题。信息足够时立刻停止，不必凑满6个。

问诊结束后，请整理出：
1. 我最开始问的问题；
2. 我真正想解决的问题；
3. 已经确认的事实；
4. 仍未验证的假设；
5. 最可能改变结论的关键变量；
6. 一个准确、具体、可以继续行动的新问题。
等我确认这个新问题以后，再给出你的判断、理由和下一步行动。
~~~

## 追问至足够理解

比苏格拉底问诊更短，适合目标已经大致明确、只需要补齐上下文时。

~~~text
【你的问题/需求】请你在回答前，先问我问题。
要求：一次只问一个问题。
根据我的回答，继续追问。
直到你有95%的信心理解我的真实需求和目标。
然后才给出方案。
~~~

> [!note]
> “95%”是停止追问的启发式阈值，不是可校准的统计置信度。更稳妥的停止条件是：目标、约束、成功标准和关键事实已经明确。

## 先选专家视角

适合问题清晰，但不知道应该采用哪个专业视角时。

~~~text
我想探讨【领域】里的【问题类型/场景】。先别回答。
请你先选一位最适合的领域顶尖名人专家来思考它。可以是活人或历史人物，名字可以小众，但必须在该细分领域很专业。
如果你不确定该选谁，可以先反问我2个定位问题再选。

先输出：
1. 你选谁，他对应的细分领域
2. 为什么选他，三句话

然后再让我描述详细的问题。
~~~

> [!warning]
> 真实人物角色适合帮助选择分析视角，不应要求 AI 编造该人物没有公开表达过的观点。需要多学科协作时，优先使用 [[AI/提示词/分析决策与解决问题提示词#专家会诊]]。

## 自优化 Prompt

适合通过多轮迭代把一个模糊需求改写成清晰、可执行的提示词。

~~~text
我想让你成为我的 Prompt 创作者。你的目标是帮助我创建最佳的 Prompt，这个 Prompt 将由你使用。
你将遵循以下过程：
1. 首先，你会问我 Prompt 是关于什么的。我会告诉你，但我们需要通过不断迭代来改进它。
2. 根据我的输入，你会创建三个部分：
   a) 修订后的 Prompt：清晰、精确、易于理解；
   b) 建议：还应该补充哪些细节；
   c) 问题：为改进 Prompt，还需要我提供哪些信息。
3. 你提供的 Prompt 应采用我向 ChatGPT 发出请求的形式。
4. 我会继续补充信息，你持续更新“修订后的 Prompt”，直到它完整为止。
~~~

## 选择建议

- 问题本身可能问错了：用“苏格拉底式问诊”。
- 问题没错，但背景信息不足：用“追问至足够理解”。
- 不知道采用什么专业视角：用“先选专家视角”。
- 已知任务方向，只想打磨 Prompt：用“自优化 Prompt”。
